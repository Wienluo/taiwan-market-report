18. 產業 Bottleneck / Content Value

目前我把研究優先序調整成：

① High-speed / high-power interconnect

高速線、AEC/ALC、800VDC、高功率線束同時增加：

  • ASP
  • specification
  • switching cost
  • qualification barrier

這使連接線束首次升到高優先級。

② ASIC / Test capacity

晶片 complexity 上升後：

Test time/chip↑

比單純晶片數增加更能推升 content value。

③ ABF / Glass cloth

ASIC、switch的 package / PCB complexification 仍推升材料價值。

④ Optical / SOI

roadmap 正確，但量產 timing 與估值不確定性較高。

Memory

今天開始正式由：

Bottleneck trade

轉成：

Supply-response trade。
