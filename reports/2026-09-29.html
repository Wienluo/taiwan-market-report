0-4. 近期市場觀點濃縮

目前較適合的模型仍是：

經濟／企業獲利很強，但代價是利率更高、更久。

因此不是典型衰退熊市，也不是上半年「有AI故事就全面rerating」的easy period。

策略重點應從「確認市場是否risk-on」轉成：

10Y從5.1%再升至5.24%左右，加上信用市場開始出現壓力，因此buy-the-dip的前提必須變得更嚴格：必須是earnings仍上修、RS仍強、且沒有good-news failure的公司。

4. Price Leads Fundamentals

4-1. 聯發科：今天最重要的 Price Warning

聯發科9/24收5,285元，連假後9/29直接跌至 4,910元、-7.1%。

目前沒有同步出現公司基本面崩壞的證據。

所以較合理標記為：

Fundamental 尚未證偽 × Technical 明顯轉弱

可能原因依優先順序：

  1. 前期漲幅過快、position crowded。
  2. 高PE對5.2%以上殖利率高度敏感。
  3. ASIC expectation已price-in。
  4. 市場開始重新檢視競爭／訂單預期。

現在不能直接推導「ASIC基本面轉空」。

但如果之後：

  • 好消息出現仍不能反彈；
  • RS持續降低；
  • 同ASIC/IP族群同步失去支撐；
  • earnings estimate開始下修；

就應提高「price leads fundamentals」的權重。

4-2. CCL／PCB：Fundamental仍強，但Technical由全面確認轉為分化

這裡反而新增了很重要的基本面證據。

優分析9/29最新研究指出，高階CCL真正瓶頸已不只是CCL壓合，而往上游移動到：

Low-Dk玻纖布
＋超薄電子布
＋HVLP／低粗糙度銅箔。

建滔的Low-Dk玻纖紗／布新增產線預計從 2026H2 開出，RTF/HVLP高速銅箔則規畫 2027年中 增加供應。

這得到兩個相反結論：

支持

shortage是真的。

不是純市場敘事，因為上游廠已經實際投入CapEx解決瓶頸。

反對

shortage不是永久的。

真正要追蹤的是：

2026H2 → 2027新增供應後，需求成長能否繼續快於供給。

這是目前PCB thesis最重要的falsification timeline。

8. 優分析／MoneyDJ 深讀

① CCL：瓶頸從CCL廠移向上游材料

今天最有價值的基本面更新就是這一點。

過去模型容易寫成：

AI Server → CCL缺貨 → CCL廠受惠。

現在應改成：

AI Server → 高速signal要求提升 → Low-Dk／Low-Df材料要求提高 → 玻纖布／HVLP銅箔／樹脂成為限制條件 → CCL廠即使有機台，也可能因原料不足無法滿載。

而且摩根大通近期研究進一步指出，下一個材料差異化可能由玻纖／銅箔延伸至 resin formulation。

因此投資研究不能只停在「哪家CCL產能最大」，而應追蹤：

material qualification + proprietary formulation + raw-material allocation。

② 晶技：1.6T upgrade開始轉成可量化CapEx

MoneyDJ 9/29資料提供了比「1.6T會成長」更好的驗證資料：

  • 7億元CapEx。
  • 新增5KK。
  • 2027H1訂單能見度。
  • AI營收占比由2025年11%升至2026年約16%。
  • 前8月稅前盈餘17.91億元，YoY +29.7%。

這種證據品質高於單純題材：

roadmap → qualification → capacity → orders → earnings

已經串起來。

③ CPO：Technology validation > Revenue validation

ELSFP small-volume是進步，但不能把「量產準備」等同「大量營收」。

核心驗證仍然是：

CSP deployment × socket/content × customer qualification × actual volume order。

11. Bottleneck / Content Value

目前AI hardware真正值得持續研究的瓶頸，大致依序是：

HBM／先進封裝
→ ABF／高階CCL材料
→ 高速網路／光通訊
→ Power delivery
→ Cooling

其中PCB今天新增的重要認知是：

Bottleneck在往 upstream materials 移動。

不是單純PCB加工產能。

而產品升級：

M7 → M8 → M9
800G → 1.6T
GPU cluster功率↑

共同增加：

  • ASP
  • content per system
  • engineering complexity
  • qualification barrier
  • switching cost

這才是長期investment thesis，而不是「AI出貨多所以大家營收都增加」。

12. 籌碼與槓桿

今天已確認：

外資現貨 -632億元。

這個數字遠比9/24的-329億元更值得注意。

而且：

Price ↓ + Foreign selling ↑

目前沒有籌碼背離，是一致偏空。

但仍缺今天融資與外資期貨正式數據，因此不能判斷：

  • 散戶是否逢低加槓桿；
  • 外資是否用期貨同步增加避險；
  • 是否已開始forced deleveraging。

所以今天不能下「籌碼全面惡化」結論。

正確寫法應是：

Institutional cash positioning明顯惡化；leverage confirmation待資料。

今日最重要的一句話

9/29不是「AI基本面轉空」，而是市場開始要求更高的earnings quality，來補償5.2%以上的無風險利率。

因此目前不能簡單用：

「債息高 → 市場一定崩」

也不能繼續用：

「AI成長強 → 每次跌都是無條件買點」。

更合理的模型是：

Fundamental growth必須快到足以抵銷WACC上升；只有同時具備earnings revision、bottleneck/content growth與relative strength的股票，才配得上目前的高估值。

所以相較9/24，我會把你的原先策略做一個小幅度調整：

維持既有合理exposure可以，但新增exposure的門檻提高。

現在真正要等待的不是「大盤跌夠了沒有」，而是：

哪一批9/29被valuation compression打下來的leader，在接下來1–5個交易日最先停止下跌、重建RS。

那群股票才會是下一個M.E.T.A./pullback setup最值得研究的候選。
