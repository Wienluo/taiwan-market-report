這是今天最大的 Fundamental update之一。

TrendForce 9/23 最新DRAM研究仍指出供需偏緊，主因AI Server、HBM與Server DRAM持續排擠一般DRAM產能，新增產能尚不足以立即解除 shortage。

NAND更有直接證據。

群聯表示：

  • NAND訂單滿足率僅約 30%

因此9/21看到 CXMT 新供給開始出現後，我不會再直接推：

Memory shortage已經被證偽。

比較合理是：

Near-term shortage仍強，但 medium-term supply elasticity正在增加。

也就是：

現在

Demand > Supply

研究重點

不是「缺不缺」

而變成：

shortage還能維持多久？

這是 cycle 後半段應有的問題。

20. 產業瓶頸與 Content Value

目前真正值得追的瓶頸排序，我會改成：

① Advanced process consumables / equipment
2nm/A16使CMP步驟與耗材用量結構性增加。

② NAND / enterprise storage
供貨滿足率仍低，而且AI inference把storage變成新content來源。

③ Advanced substrate / PCB materials
ASIC、switch提高area / layer / specification。

④ Optical / Ge-Si / InP
technical barrier高，但valuation也非常高。

⑤ Interconnect / cable / rack infrastructure
AI從單機變成整rack，Content Value由單一connector轉向完整interconnect system。

相較之下：

Test、MLCC、滑軌雖然產業仍好，但目前投資問題已經從「需求夠不夠」變成「價格是否先走太遠」。
